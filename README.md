# Nour Academy

Nour Academy is a web project that helps parents find the right school support and language courses for their children. It simplifies course selection and the registration process.

## Features

- Browse available courses.
- Search for courses by name.
- Filter courses by level and subject.
- Add courses to the cart and calculate the total price.
- Fill in a registration form.
- Responsive design for desktop, tablet, and mobile.

## Technologies

- HTML
- Tailwind CSS
- JavaScript
- Vite

## Installation

Clone the repository:

```bash
git clone https://github.com/chrdalachraf85-blip/Nour-Academy.git
```

Navigate to the project folder:

```bash
cd Nour-Academy
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Project Goal

The goal is to make course selection easier for parents and simplify student registration at Nour Academy.
